# Arcane-Drafter

Public issue tracker and discussion hub for **[Arcane-Drafter-Godot](https://github.com/Git-Lamurette/Arcane-Drafter-Godot)**.

This repository contains no game code. It exists so players and contributors have a single place to:

- Report bugs
- Request features
- Ask questions and chat in [Discussions](../../discussions)
- Browse known issues, FAQs, and guides in the [Wiki](../../wiki)

## Filing an issue

Please use one of the issue templates:

- [Report a bug](../../issues/new?template=bug_report.yml)
- [Request a feature](../../issues/new?template=feature_request.yml)

Before opening a new issue, search [existing issues](../../issues?q=is%3Aissue) to avoid duplicates.

## Pull requests

This repository does not accept pull requests. Only the maintainer pushes here. If you have a fix or improvement for the game itself, please open an issue first to discuss.

Participation in this tracker is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
