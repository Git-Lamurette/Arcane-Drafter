# Arcane-Drafter — Issue Tracker

> **This repository is used exclusively for tracking bugs and feature requests for the [Arcane-Drafter-Godot](https://github.com/Git-Lamurette) project.**
> There is no source code here — please do not open pull requests.

---

## What is Arcane-Drafter?

Arcane-Drafter is a Godot-based application. This companion repository serves as the public issue tracker so players and testers can report problems and suggest improvements without needing access to the main (private) source repository.

---

## Reporting a Bug 🐛

1. Check the [existing issues](../../issues) to see if the bug has already been reported.
2. Click **New Issue** and choose the **Bug Report** template.
3. Fill in as much detail as possible (steps to reproduce, expected vs. actual behaviour, screenshots, Godot version, OS, etc.).

## Requesting a Feature 💡

1. Check the [existing issues](../../issues) to see if the feature has already been requested.
2. Click **New Issue** and choose the **Feature Request** template.
3. Describe the feature and explain why it would be useful.

---

## Guidelines

- Be respectful and constructive.
- One issue per report — please don't bundle multiple bugs or requests together.
- If you have a question rather than a bug/feature, use the **Question** label when opening an issue.
