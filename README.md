# Arcane-Drafter

Public issue tracker and discussion hub for **[Arcane-Drafter-Godot](https://github.com/Git-Lamurette/Arcane-Drafter-Godot)**.

This repository contains no source code. It exists so users and contributors have a single place to:

- Report bugs
- Request features
- Ask questions and chat in [Discussions](../../discussions)
- Browse known issues, FAQs, and guides in the [Wiki](../../wiki)

## About the tool

**Arcane-Drafter** is a map-making tool for tabletop role-playing games (TTRPGs). It's aimed at GMs and worldbuilders who want to put together maps for their sessions without wrestling with general-purpose art software.

- Built with the **[Godot Engine](https://godotengine.org/)**
- Currently in **early development** — expect rough edges, breaking changes, and missing features
- **Feedback and playtesters welcome** — please file issues with what works, what doesn't, and what you'd like to see

If you're new here, the [Wiki](../../wiki) is the best place to start.

Please use one of the issue templates:

- [Report a bug](../../issues/new?template=bug_report.yml)

This repository does not accept pull requests. Only the maintainer pushes here. If you have a fix or improvement to suggest, please open an issue first to discuss.
